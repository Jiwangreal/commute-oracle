# 演示录屏脚本（≤ 5 分钟）

> 目标：让评委在 5 分钟内看懂「它解决什么问题 → 怎么用 → 背后真的调了高德」。
> 建议 1080p / 30fps，浏览器缩放到 100%，窗口 1440×900。

## 录制前 2 分钟准备

- [ ] 打开 <https://jiwangreal.github.io/commute-oracle/>，确认右上角是 `LIVE` 且有数据时间
- [ ] 点一次「重置演示」，确保没有注入事件
- [ ] 点击「系统通知」开关并授权（录屏里能看到真实系统通知）
- [ ] 关闭无关标签页、微信/邮件通知，开启勿扰模式
- [ ] 鼠标移动到画面右下角，避免遮挡结论卡

## 分镜

### 00:00–00:25 开场：先给结论

**操作**：停留在首屏，不滚动。

**念白**：
> 每天早上我们都要做一个决定：几点出门。绝大多数人是上车才打开地图，看到一片红，然后焦虑。
> 通勤先知把这件事提前到前一晚：它直接告诉你，明早几点走、走哪条、为什么、有多大把握。
> 比如今天：周一 07:50 出发，比平时早 10 分钟，预计 08:58 到，把握 72%。

**画面重点**：大号出发时间、差值、到达时间、风险与把握。

### 00:25–01:05 为什么：把黑盒拆开

**操作**：鼠标移到右侧「为什么是这个时间」，逐条指过堆叠条与三条证据，再点开一条 API 日志。

**念白**：
> 这个时间不是拍脑袋。总耗时被拆成四段：自由流 26 分钟、早高峰多 36 分钟、天气和突发各占多少。
> 证据来自三个真实接口：高德天气、高德交通态势、以及这条走廊的历史早高峰曲线。
> 底部是高德 API 日志，每一次请求的耗时和原始返回都能展开。

### 01:05–01:35 未来 7 天：不止明天

**操作**：横向点「周三」「周四」，展示不同日期的时间与风险；指出「外推」标签。

**念白**：
> 未来 7 天每天都有一个建议。周三是真实预报，周四是趋势外推，我们会明确标注，不假装能预知七天后的暴雨。

### 01:35–02:20 暴雨：系统会改口

**操作**：滚到「演示控制台」，点「明早暴雨」。

**念白**：
> 现在模拟一场暴雨。注意看，推荐时间从 07:50 跳到了 07:35，风险从低变成高，天气一项多出 26 分钟。
> 同时右上角弹出播报——这就是明早 07:30 你会收到的那条通知。

**画面重点**：Hero 变红、通知卡片、堆叠条里的紫色天气段。

### 02:20–02:55 事故：路线重排

**操作**：再点「京通快速事故」，指地图上的事故标记与重新排序后的备选路线。

**念白**：
> 再叠加一起事故。地图上出现事故点，主路线耗时重新计算，推荐时间继续提前到 07:25，备选路线按新的耗时重新排序。
> 这时候「多睡十分钟」和「不迟到」之间，系统替你做了取舍，并告诉你代价。

### 02:55–03:35 时间旅行：明早打开地图的那一刻

**操作**：点「模拟当天 07:30」。页面顶部出现通知，LIVE 变成 DEMO，时间轴切到当天。

**念白**：
> 现在是明早 07:30，你刚打开地图。不需要搜索、不需要输入终点，结论已经在这里。
> 点通知，直接回到路线；点「开始导航」，唤起高德导航。

**操作**：点「开始导航」，展示 URI 唤起（若录屏环境没有高德 App，可只展示跳转后的网页）。

### 03:35–04:10 真实调用：证明不是死数据

**操作**：点「重置演示」→ 点右上角刷新按钮 → 展开 API 日志 → 点一条「驾车路径规划」看原始 JSON。

**念白**：
> 刷新一次，7 个高德接口并行请求：两地天气、三个点的交通态势、驾车路径规划、公交路径规划。
> 这条是真实的驾车路径规划返回，包含每一段的 TMC 路况和耗时。

### 04:10–04:40 收尾：价值与落地

**操作**：回到首屏，缓慢滚动一次全页。

**念白**：
> 对用户，它省下的是每天早上的焦虑和迟到；对高德，它把「出发后导航」变成「出发前决策」的高频入口；对企业，它可以把「明天大面积迟到」变成可提前干预的运营事件。
> 通勤先知：明早几点走，今晚就知道。

### 04:40–05:00 片尾

- 在线地址 + GitHub 仓库二维码
- 一行字：数据来自高德开放平台 · 预报第 5–7 天为趋势外推 · 事故与暴雨为演示注入

## 备用镜头（若时间富余）

- 打开「设置」，把家改成「天通苑北地铁站」，保存后展示重新地理编码与路线重算。
- 手机端录屏 15 秒，展示移动端布局。
- 点「地铁故障」，展示公交方案变红、系统建议仍以驾车为主。

## 剪辑提示

- 关键数字处加 0.3 秒定格或放大。
- 通知弹出、Hero 变色处加轻微音效。
- 全程字幕，重点数字加粗。
- 不要剪掉「外推」「演示注入」标注——诚实是加分项。
