## 二、数据与能力来源

1. 本作品的地图底图、路况图层、路线规划、天气、地理编码等能力，均通过**高德开放平台**的 JS API 2.0 与 Web 服务 API 获取，遵守《高德开放平台服务条款》及相关协议。
2. 页面内「高德 API 调用日志」实时展示每一次真实请求；`data/fallback-snapshot.json` 保留了构建期的原始返回，供核验。
3. 作品未抓取、未存储、未转售任何第三方地图数据；未绕过任何接口配额或鉴权机制。

## 三、隐私与数据安全

3. 演示所用的高德 Key 仅用于赛事演示，正式上线前将配置域名白名单、配额与安全密钥。

1. 出发时间、到达时间、风险与置信度均为**估算值**，不构成出行承诺。

3. 作品不宣称能够预知交通事故；事故与暴雨情景为**演示注入**，界面已标注「演示注入」。
